# OVEN EXPRESS - Food Ordering System

OVEN EXPRESS is a comprehensive food ordering system designed for a restaurant. It provides a user-friendly interface for customers to browse the menu, place orders, and track their deliveries. It also includes an admin dashboard for restaurant management.

## Features

- User-friendly landing page with today's special offers
- Extensive menu with categorized food items
- Shopping cart functionality
- User account management
- Order tracking system
- Admin dashboard for restaurant management
- Offer management system
- Responsive design for mobile and desktop

## Tech Stack

- React (Frontend)
- Tailwind CSS
- MongoDB (Database)
- Node.js, Express.js
